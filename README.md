# Pushkar_shau_ERP_RU-25-11065_MINI_PROJRCT_
The aim of this project is to create a Number Guessing Game that allows the user to guess a secret number within limited attempts, providing hints and indicating success or failure.

"Step 1: Store a fixed secret number in a variable.
Step 2: Decide the maximum number of attempts allowed.
Step 3: Use a loop to give the user limited chances to guess.
Step 4: Inside the loop, ask the user to enter their guess.
Step 5: Read the user’s input using scanf.
Step 6: Compare the input with the secret number.
Step 7: If the guess is correct, print a success message and exit the loop.
Step 8: If the guess is too high, print a hint saying “Try smaller number.”
Step 9: If the guess is too low, print a hint saying “Try larger number.”
Step 10: If all attempts are used without a correct guess, print a failure message."
